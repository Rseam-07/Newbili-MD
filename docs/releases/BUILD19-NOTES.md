# Newbili MD 1.1.0 · Build 19

Android 与 iOS / iPadOS 同步更新缓存、可靠性和细节动效。

## 本次改进

- 新增“存储与缓存”：后台统计图片与临时文件，支持调整上限和立即清理。默认图片缓存从 1 GB 调整为 256 MB，保留有效的自定义设置。
- 浏览时自动回收较久未访问的图片；修复清理与下载、索引写入竞争，保留离线视频、账号和使用中的文件。
- 导出临时文件任务完成后释放；限制播放预览图片内存，修复退出播放后晚到回调和动图转换重复释放。
- 设置、观看记录、收藏等入口加入可打断的按压回弹；存储数字、进度与选择状态连续变化，适配大字体及减少动态效果。
- 包含此前验证码白屏、重复 UP 主信息、动态图标、操作按钮和联合投稿网页跳转修复。

## 安装

- [官网直链与更新日志](https://rseam-07.github.io/downloads/)；大多数 Android 手机与平板选择 `arm64-v8a.apk`。
- Android 12 及以上，沿用原测试渠道包名与签名，可覆盖旧 MD 测试版，请勿先卸载。
- iOS / iPadOS 15 及以上：`iOS-unsigned.ipa` 为未签名包，需要自己的有效签名。
- 三份 APK 和 IPA 的 SHA-256 见附件 `SHA256SUMS-1.1.0-build19.txt`。

## 验证边界

16 项缓存策略、图片生命周期、页面布局和交互定向检查已通过，复用同一份共享应用代码的结果，不重复跑全量测试。三种 Android 包的版本、原签名、ZIP 和原生库 16 KB 对齐已核验；Android 12 模拟器覆盖升级、缓存清理和重启后上限保留通过。两端共用版本与发布流程；iOS 复用已经验证的 Build 19 Release IPA。

真机登录、长时间后台播放与缓存空间变化仍需实际设备验收。iOS 系统画中画及原生后台下载尚未实现。具体构建与 Android 安装检查见附件 `VALIDATION-1.1.0-BUILD19.json`。
