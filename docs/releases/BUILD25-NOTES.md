# Newbili MD 1.2.0 · Build 25

展开的空间，真正用起来。依据 Apple 官方 Duo 设计说明，重新安排播放、控制、内容和导航，保留 Material Design。

- 展开横屏自动打开视频与简介／评论／动态双栏；展开竖屏使用全宽视频与下方内容。
- 书本姿态在左上播放、左下提供标题、进度、字幕、倍速与前后 10 秒操作，右侧保留内容。
- 补充帐篷观看：外屏横向优先放大视频，评论按需覆盖展开；有可靠铰链状态时自动选择，支持手动入口。帐篷姿态新增定向逻辑检查，未完成真实帐篷设备姿态验收。
- 桌面姿态上方观看、下方操作与评论；折叠姿态全屏继续利用第二区域。
- 侧边操作栏合并系统安全区，返回、主页、布局、内容、弹幕和菜单留在外侧，避让摄像头及状态区。
- 折叠屏首页缩小推荐横幅，展开网格优先偶数列，左右区域各自利用宽度；普通平板保留原设计。
- 修复桌面控制区退出全屏，书本触控区支持大字体滚动。两端共用实现，Android 沿用旧测试渠道签名，可覆盖更新。

## 验证边界

受影响布局、标签、连续播放与网格检查通过，无重复整套测试。iOS 27.1 Duo 模拟器实际播放过程中，书本、桌面、全屏、展开横竖屏及合拢外屏保持同一播放器、解码器、纹理控制器和已选评论页，进度持续增加。此记录针对 debug host 与 Build 25 Flutter 源码，最终原生桥接编译和安装包校验另见 VALIDATION 文件。真机功耗、帧时间、系统分屏和登录互动没有在本轮重新验收。iOS IPA 未签名，需要自己的有效签名。
